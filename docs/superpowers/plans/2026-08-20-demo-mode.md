# Demo Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A per-user, toggleable Demo mode that runs the whole product inside a disposable, anonymised copy of the user's workspace — nothing real on screen, nothing persisted, nothing sent out.

**Architecture:** Entering demo mode clones the real workspace into a second `Organization` (`kind: 'demo'`), anonymising every value as it copies (deterministic alias book). `requireAuthContext` redirects the request's `organizationId` to the demo org when the demo cookie is present, so existing tenancy (tenant guard + RLS) provides isolation. Outbound transports (Nango proxy, HTTP steps, email, Slack, MCP) short-circuit to canned responses when the ambient org is a demo org. Exit = cookie cleared + existing `teardownOrganization`.

**Tech Stack:** Next.js App Router, Prisma/Postgres (RLS), existing PII detectors (`src/lib/security/pii-egress.ts`), node:crypto for deterministic hashing.

**Spec:** `docs/superpowers/specs/2026-08-18-demo-mode-design.md`

## Global Constraints

- Alias book and anonymiser are PURE modules: no DB, no env, no clock (pattern: `src/lib/catalogue/sanitize.ts`).
- Determinism: `hash(realOrgId + normalisedValue)` — same real value → same alias across snapshots and re-entry.
- Demo org grants nothing via `kind`: `'demo'` must never appear in `REVIEWING_ORG_KINDS` / `OPERATING_ORG_KINDS` (`src/lib/authz/permissions.ts`); permissions are resolved from the REAL org before the swap.
- Credentials are never copied: no `IntegrationSecret`, `HttpCredential`, `ApiKey` rows; connection rows are shells with no token material.
- All snapshot/teardown DB work uses `systemPrisma` with org ids pinned (pattern: `src/lib/org-teardown.ts`).
- One demo org per user: unique constraint on `demoOwnerUserId`.
- No raw token syntax in UI copy (user mandate); chip copy is plain English.
- Gates: `npx tsc --noEmit`, targeted `npx vitest run` per task; CI-mode DB tests before push.

```ts

import { createAliasBook } from '../alias'

describe('alias book', () => {
  it('is deterministic per org', () => {
    const a = createAliasBook('org-1').company('Acme Corp')
    const b = createAliasBook('org-1').company('Acme Corp')

  })

    const company = book.company('Acme Corp')

  })
  it('never returns the real value', () => {
    const book = createAliasBook('org-1')
    expect(book.company('Acme Corp').name.toLowerCase()).not.toContain('acme')
  })
})
```
